# Política de segurança

## Versões suportadas

Correções de segurança são direcionadas à branch `main` e à linha pública mais
recente, atualmente `0.4.x`. Versões anteriores podem não receber correções.

## Relato responsável

Não abra uma issue pública para vulnerabilidades, credenciais expostas ou um
problema que permita execução não autorizada. Use a opção **Report a
vulnerability** na aba Security do repositório para iniciar um aviso privado.

Inclua versão, impacto, passos mínimos de reprodução e uma forma segura de
validar a correção. Não inclua tokens, dados pessoais ou cubos não públicos.

HyperMix é software de pesquisa. Ele não deve ser usado como sistema clínico,
de segurança ou de decisão crítica sem validação independente.
