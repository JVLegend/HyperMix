# HyperMix v0.5.0

Esta release transforma o HyperMix em um benchmark auditável e preparado para
instalação pública. Ela não anuncia superioridade do aprendizado.

## Principais entregas

- benchmark em cinco regimes de detecção, com matched filter espacial como
  comparador obrigatório;
- incerteza calibrada com NLL, Brier, ECE e curvas de confiabilidade;
- análise de esparsidade de bandas;
- detector auto-supervisionado de fundo, RX e Pd@FAR com bootstrap;
- aquisição rastreável e loader ENVI para o cubo bioHSI real de 54 m;
- protocolo regional e porta de reprodução pré-especificada para a Figura 4g;
- observatório web bilíngue, responsivo e acessível;
- CI em Python 3.10 a 3.14, suíte completa em Python 3.11, wheel limpa e
  publicação PyPI por OIDC.

## Resultado científico preservado

Nos experimentos concluídos, nenhum método aprendido superou de forma robusta
um matched filter espacial bem calibrado. O clássico calibrado também foi igual
ou melhor nas métricas de incerteza. O valor defensável do HyperMix é o
benchmark aberto, não um detector superior.

A avaliação sobre alvo bioHSI realmente medido continua pausada. As caixas
candidatas não reproduziram os nove scores publicados da Figura 4g, inclusive
quando o código oficial foi executado diretamente. O arquivo manual de
coordenadas solicitado pelo notebook não está no arquivo público. Nenhuma
comparação entre detectores foi realizada nesse dado.
