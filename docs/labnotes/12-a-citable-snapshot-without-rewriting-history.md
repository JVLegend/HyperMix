A ordem dos eventos importou. A GitHub Release já existia quando a integração
do Zenodo foi habilitada, e a ingestão automática não retroagiu. Em vez de
apagar e recriar a release ou provocar um segundo upload ao PyPI, preservamos o
estado público e depositamos manualmente o ZIP exato da tag `v0.5.0`.

`7ddd27d785bcdad6fd9ccefc66e1c5cb` no Zenodo. A tag aponta para o commit
`e60cef1302f72885979b88b947871c3ec549fa4e`. O registro público foi conferido
pela API do Zenodo: estado publicado, software, versão `0.5.0`, acesso aberto e
licença MIT.

O DOI torna a versão citável, mas não muda o resultado científico. Nos
experimentos concluídos, nenhum método aprendido superou de forma robusta o
matched filter espacial bem calibrado. A contribuição continua sendo o
benchmark aberto, reproduzível e disposto a publicar resultados negativos.
